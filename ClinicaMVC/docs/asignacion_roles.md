**2. Descripción del Proyecto**

**El Sistema de Gestión de Clínica es una aplicación de software
diseñada para administrar de forma eficiente los procesos internos de
una clínica médica. El sistema contempla los siguientes módulos:**

  ------------------------------------------------------------------------------
  **\#**   **Módulo**        **Descripción**
  -------- ----------------- ---------------------------------------------------
  1        **Pacientes**     Registro, edición, eliminación y búsqueda de
                             pacientes. Campos: nombre, cédula, fecha de
                             nacimiento, teléfono, dirección, tipo de sangre.

  2        **Médicos /       CRUD de médicos con especialidad y horario
           Especialistas**   disponible. Campos: nombre, cédula, especialidad,
                             teléfono, turno (mañana/tarde).

  3        **Citas Médicas** Agendar cita vinculando paciente + médico +
                             fecha/hora. Verificación de disponibilidad.
                             Estados: Pendiente, Atendida, Cancelada.

  4        **Consultas /     Al atender una cita, registrar diagnóstico,
           Historial         síntomas y tratamiento. El historial queda
           Médico**          vinculado al paciente.

  5        **Usuarios y      Login con roles: Administrador, Recepcionista,
           Seguridad**       Médico. Cada rol accede solo a lo que le
                             corresponde.
